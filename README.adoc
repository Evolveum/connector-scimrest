= Polygon SCIMREST Connector Framework

Framework and set of connectors for various services using SCIM 2 and REST.

The intent of the SCIMREST framework is to simplify building customized connectors using a declarative approach, a set of prebuilt components and strategies, with the option to customize behaviour using Java or Groovy code.

== Structure

* link:common/[`common`]:
Common base Java framework for implementing SCIM & REST based ConnId connectors.
** Supports custom Java lambdas / classes for behavior customization
** Supports custom Groovy scripts (using a DSL and lambdas) for behavior customization

* link:connector/[`connector`]:
Contains hand-crafted implementations of generic and application-specific connectors, created on top of the common connector framework.
** link:connector/forgejo/[`forgejo`]: Forgejo connector implemented with Groovy scripts and a `connector.manifest.json` that loads them from the classpath.
** link:connector/generic/[`generic`]: Fully generic, configuration-driven connector (REST + SCIM) with an empty manifest — no bundled scripts; behaviour comes from the configuration and the framework defaults.

* link:docs/[`docs`]: Documentation of the connector framework (AsciiDoc under `src/main/asciidoc/scimrest/`).
** link:docs/src/main/asciidoc/scimrest/develop/[`develop`]: Development guides — REST, SCIM 2.0, authentication, declarative YAML, and custom search.
*** link:docs/src/main/asciidoc/scimrest/develop/rest/index.adoc[`rest`]: Step-by-step description of the necessary steps to implement a REST connector.
