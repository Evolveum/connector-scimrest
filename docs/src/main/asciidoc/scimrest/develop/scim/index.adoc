= Develop SCIM 2.0 connector using Polygon SCIMREST framework

This is a reference for developing SCIM 2.0 connectors using the SCIMREST framework.

== Documentation structure

The SCIM 2.0 connector tutorial is organized as progressive steps:

* xref:schema-discovery.adoc[Schema discovery] - Automatic SCIM schema discovery from the server
* xref:schema-customization.adoc[Schema customization] - Customizing discovered schema with Groovy scripts
* xref:complex-attributes.adoc[Complex and binary attributes] - SCIM path mappings and embedded object classes
* xref:search.adoc[Search operations] - Built-in search (UID retrieval, list-all, server-side filtering) and filter declarations
* xref:create.adoc[Create operations] - Creating resources via SCIM POST
* xref:update.adoc[Update operations] - Updating resources via full PUT
* xref:delete.adoc[Delete operations] - Deleting resources via SCIM DELETE
* xref:advanced-filters.adoc[Advanced filters] - Filter specifications
* xref:relationship-support.adoc[Relationship support] - Handling SCIM relationships

== Get started with SCIM 2.0 framework

The SCIMREST Framework provides built-in support for SCIM 2.0 protocol, handling schema discovery, filtering, and standard operations while allowing customization through Groovy DSLs.

=== SCIM 2.0 specific features

The framework includes:

* *Automatic schema discovery* - SCIM schemas are automatically discovered from the server
* *SCIM-specific operations* - Built-in search (UID retrieval, list-all, and server-side filtering) and update (default SCIM `PATCH` for partial updates; optional full `PUT` for full replacement)
* *Attribute mapping* - SCIM path-based attribute resolution
* *Customizable* - Override default behavior with Groovy DSLs when needed



== Initial development steps

=== Read-only connector

. Obtain the documentation for the service/application
. Determine connection & authentication parameters (see xref:../authentication.adoc[])
. Implement test connection
. Determine object classes and their attributes
. Schema discovery is automatic - verify the discovered schema in development mode
. xref:search.adoc[Verify search and UID retrieval for each object class] (built-in; customize or replace with a custom implementation if the server deviates)
. Determine relationships between object classes
. xref:relationship-support.adoc[Verify relationship support] (standardized `groups`/`members` relationships are detected automatically)

=== Read-Write Connector

In addition to read-only steps:

. xref:create.adoc[Verify the create operation] (built-in for well-behaved servers)
. xref:update.adoc[Verify the update operation] (built-in full PUT)
. xref:delete.adoc[Verify the delete operation] (built-in)
