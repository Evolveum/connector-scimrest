= How to develop connectors using SCIMREST framework

This section provides two development guides for building connectors with the Polygon SCIMREST framework.

The REST guide section covers connector development for generic REST APIs.
It walks through initial setup, schema definition, search implementation, and—for read-write connectors—create, update, and delete operations using Groovy DSLs.

The SCIM 2.0 guide section covers connector development specifically for SCIM 2.0 compliant services.
It follows the same progression but takes advantage of the built-in SCIM support of the framework, including the automatic schema discovery and the native handling of SCIM search (UID retrieval, list-all, and server-side filtering), create, update (SCIM `PATCH` by default, with an optional full `PUT`), and delete.

Shared topics that apply to both REST and SCIM connectors: authentication & authorization, shipped and sample connectors, and declarative YAML.

Both guides address read-only and read-write connector development.
If you are unsure which guide to follow, use the SCIM 2.0 guide when the target service exposes a SCIM 2.0 compliant API;
otherwise, use the SCIMREST connector guide.
