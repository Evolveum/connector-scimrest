= Authentication & authorization

The SCIMREST framework authenticates against the target system per *protocol namespace*:

* `rest` — the REST API (properties `rest*`, scripts `authorization { rest { ... } }`)
* `scim` — the SCIM API (properties `scim*`, scripts `authorization { scim { ... } }`)

The two namespaces are independent: you can authenticate the SCIM API with one method and the
REST API with another.

This screen lists the methods the target application supports and lets you pick which ones the
connector should use. The methods are implemented by the framework out of the box — choosing a
method is usually all that is needed. Customizing how a method is applied (extra headers,
non-standard token handling, …) happens in the *Authentication Script* screen.

IMPORTANT: SCIM support is enabled only when a `scimBaseUrl` is configured *and* SCIM
credentials are present; otherwise the SCIM context is not initialized and the connector works
REST-only (with a log entry noting this).
