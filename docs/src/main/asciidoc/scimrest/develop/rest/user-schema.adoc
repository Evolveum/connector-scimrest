= Describe user schema

How to define a user object class schema in a SCIMREST connector using a Groovy builder script, including attribute types, formats, and access flags.

Write a Groovy script describing the model in JSON using Groovy builder
like following:

[source,groovy]
----
objectClass("User") {
     attribute("created") {
         description "Time when user was created.";
         json {
            type  "string";
            openApiFormat "date-time";
         }
     }
    attribute("id") {
        description "ID of user";
        json {
            type "number";
            openApiFormat "int64";
        }

    }
}
----

The `json { ... }` block describes how the attribute value is represented in the JSON wire format:

* `json.type` — the JSON type used to represent the data (`string`, `number`, `integer`, `boolean`, `array`, …)
* `json.openapiFormat` — the OpenAPI format (from the https://spec.openapis.org/registry/format/[format registry]) that describes the data formatting and allowed values (e.g. `date-time`, `int64`)

The following attribute properties are available on the attribute itself:

* `description` — description of the attribute as obtained from the documentation
* `required` — is the attribute required?
* `multiValued` — does the attribute hold multiple values?
* `creatable` — can the attribute be used during the create operation; default is `true`, can be omitted
* `readable` — can the attribute be read; default is `true`, can be omitted
* `updatable` — can the attribute be modified; default is `true`, can be omitted
* `returnedByDefault` — is the attribute returned by default in read/search results; default is `true`, can be omitted

NOTE: The `updateable` spelling is accepted as an alias of `updatable` in scripts.

== The same schema in YAML

The same schema can be written as a YAML schema document:

[source,yaml]
----
objectClasses:
  User:
    attributes:
      created:
        description: "Time when user was created."
        json:
          type: string
          openApiFormat: date-time
      id:
        description: "ID of user"
        json:
          type: number
          openApiFormat: int64
----

See xref:../declarative-yaml.adoc[declarative YAML] for the full reference.
